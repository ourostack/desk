[Work orchestration](skills/work-orchestration/SKILL.md) now says agents never use the system clipboard on a machine a person uses: no copy or paste keys, no `pbcopy` or `pbpaste`. Linked devices share the clipboard and endpoint security tools read each change, so a read on one Mac fetched the other Mac's clipboard and left a stuck "Pasting from…" box on the person's screen. Text goes as key events, files or a private named pasteboard, and clipboard sharing is off on an always-on host.
