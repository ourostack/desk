The RFC now describes the kaizen loop and andon ([agentic-engineering-v2-rfc.md](docs/agentic-engineering-v2-rfc.md), section 4): the public rubric, kaizen cards checked by the store's build with a 95% bootstrap interval, and andon issues raised when a release makes a quality measure clearly worse. A fixture store test proves that andon opens an alarm and closes it once a later version recovers ([andon_regression.test.js](mcp/__tests__/factory/andon_regression.test.js)), and the README lists `curator` as the kaizen worker.
