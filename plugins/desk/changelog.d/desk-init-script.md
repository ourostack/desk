A new [`desk-init.js`](mcp/scripts/desk-init.js) script turns a folder into a fresh solo desk and commits it, so the desk layout is defined in one place. [first-run-bootstrap](skills/first-run-bootstrap/SKILL.md)'s fresh-create step now calls it, and hosted GitHub linking will call it for a repository that is not a desk yet. It refuses a folder that is already a desk without writing anything, keeps an existing README and `.gitignore` entries, commits only the files it writes, and in a hosted realm takes its root from `DESK` and runs Git without the desk path on the command line.
