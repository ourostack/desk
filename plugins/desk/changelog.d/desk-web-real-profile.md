`desk-web` can now drive the operator's real, signed-in browser profile, silently, in a window of its own. A plugin turns it on by declaring `"desk": { "browser": { "channel": "msedge" | "chrome", "profileAccountDomain": "<domain>" } }` in its `plugin.json` (the last plugin listed wins); with no declaration nothing changes, and the headless, isolated browser stays the default ([`web.cjs`](mcp/web.cjs), [`web-real-profile.cjs`](mcp/web-real-profile.cjs)).

With a declaration, the launcher finds the profile whose signed-in account ends in `@<domain>` in the browser's own `Local State` (the `user_name` field of `profile.info_cache`), reads the Playwright Extension's connection token from a temporary copy of that profile's local storage, and starts `@playwright/mcp --extension --browser <channel> --profile-dir-name <profile>` with the token in its environment. The copy is deleted at once, and the token is never printed, stored or put in a command line. Installs of `@playwright/mcp` now also install `classic-level@1.4.1`, which reads the token; an existing install without it is replaced the first time a declaration needs it.

On macOS the agent works in a window of its own. The launcher opens a new window in that browser before the first browser call reaches Playwright MCP, brings it to the front so the extension's connect page lands there, and records its id. It closes that window by that id when the agent calls `browser_close`, when the host closes stdin or stops the launcher, and when the browser process ends. It never quits the browser and never touches a window it did not open, and two sessions each close only their own. Elsewhere there is no window opening: the connect page opens in the frontmost window, and the launcher says so once on stderr.

If the declared profile has no matching account, if the Playwright Extension is not installed in it, or if the window cannot be opened, `desk-web` still starts and its first browser call answers with one degraded line (`browser_profile_not_found`, `browser_extension_missing`, `browser_token_unreadable`, `browser_window_failed` or, for a declaration it cannot use, `browser_declaration_invalid`) that names what was looked for and the fix. It never falls back to the isolated browser silently, and the next call checks again, so installing the extension needs no restart. These codes are new; the handshake and the existing codes do not change.

The extension can reach the whole browser, so the rule that an agent works only in its own window is in the [`cdp-headed-browser` skill](skills/cdp-headed-browser/SKILL.md), which now describes this mode, tells the agent to call `browser_close` when done, and limits its "never bring a window to the front" rule to brokered leases and the operator's existing windows.
