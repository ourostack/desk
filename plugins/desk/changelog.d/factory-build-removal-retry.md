The factory report build now removes its previous output folder with `removeWithRetry` ([`mcp/src/util/remove-retry.js`](mcp/src/util/remove-retry.js)), which retries EPERM, EACCES, EBUSY and ENOTEMPTY up to ten times over about a second ([`mcp/src/factory/pipeline/build.js`](mcp/src/factory/pipeline/build.js)). It relied on `rmSync`'s own `maxRetries`, which Node 24.18 does not apply to a Windows access-denied and whose Windows wait rounds to nothing.
