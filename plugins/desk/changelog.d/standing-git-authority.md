An operator's recorded standing authority to commit, push and open pull requests now counts as the explicit request a host waits for. Coding apps that run a session in the person's own checkout tell the agent to commit only when the user explicitly asks and never to push on its own, and agents with a grant in the desk were stopping there, asking a person who had already said yes. Those host defaults yield to repository guidance and the person's own instruction files, so [`interaction-style`](skills/interaction-style/SKILL.md#standing-authority) now says to take the steps the grant names without asking again, to give the grant a copy in the host's user-level instruction file, generated from the desk line by a tool and never written by hand, so it also reaches sessions in other repositories, and to point a refusing child to the exact grant line instead of relaying it.
