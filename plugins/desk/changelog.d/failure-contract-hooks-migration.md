Four more of Desk's own mechanisms now speak the shared `Desk problem: <mechanism> — <symptom>` failure contract instead of a bespoke line or a silent skip, and the boot check's own index-drift block now files for real instead of always reporting `not filed: filer_unavailable`.

`hooks/boot-checks.cjs` now emits a full block when a boot check itself throws (as opposed to running past its own time or step budget, which stays a plain skip) and queues the detached filer the same way the missing-enforcement-hook check already does; `mcp/src/runtime/pending-migrations.js`'s startup line does the same when the migration registry itself cannot be read, rather than only ever reporting the gap as unfiled. `hooks/ask-gate.cjs`'s catch-all now builds and reports the same block on an unexpected failure instead of just denying with a bare error string. `hooks/protected-checkout.cjs` keeps its plain "could not finish checking this command in time" denial and its 9 s deadline exactly as they were, but now recognizes when the *same* command has timed out three times in a row (tracked in Desk's own state directory, never inside a desk) and adds a `Desk problem: protected-checkout` block on that repeat, since a command that keeps timing out points at the guard itself needing attention rather than one slow call.

Every one of these hooks stays fast and fails open: filing is always a detached, unawaited spawn of the existing background filer script, never an inline `gh` call from a hook with a tight budget, and a broken filer never changes the decision a hook already made.
