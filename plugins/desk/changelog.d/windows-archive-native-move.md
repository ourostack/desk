Ordinary task archives on Windows now use the qualified PowerShell 5.1 `System.IO.Directory.Move` primitive rather than Node's replace-capable directory rename. A competing archive destination is refused, never treated as a successful move. The source precondition is rechecked after native readiness and before release; success requires the move acknowledgement and normal child closure. POSIX retains its existing filesystem rename.

Windows archives support qualified drive-absolute DOS paths shorter than 248 UTF-16 units, including Unicode, apostrophes and shell metacharacters as JSON data. UNC, device/verbatim namespaces, ambiguous trailing dots/spaces, reserved devices, alternate streams and unqualified long paths are explicitly unsupported; supplied and Node-resolved spellings are checked without repairing them. A released move with an unconfirmed outcome reports uncertainty rather than archive success, performs no later card/publication writes, and retains newly created parents if native retirement is unconfirmed. Retention is not ownership, rollback or permission to retry before retirement is resolved.
