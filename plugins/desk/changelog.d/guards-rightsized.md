Desk no longer watches the harness or the shell. It acts only at its own boundaries: its MCP tools, the desk repository it owns, and its own session start and end. The harness provides and supervises the tools.

Deleted, with their tests, docs, skill text, registrations and the code left without purpose: the protected-checkout guard and the `desk.protected` marker, the process-kill guard, the credential-probe guard, the task-status guard (the card pre-commit Git hook stays), host enforcement on every host including the Codex config block, the task-line deny and rewrite in the brief task-line hook (the task-line writer and binding stay), the elsewhere-clone check, the done-claim gate and the sign-off witness with its ticket store.

`task_signoff` stays. It now records the sign-off without any human-channel verification, so a sign-off recorded through the tool counts as accepted. The sign-off block no longer gets a `verified` field or any witness or ticket field. Existing cards keep their fields, and Desk readers accept both shapes. The return line no longer ends with a verification token on new records.

The boot-acceptance evals keep their done-claim measurement patterns in the harness itself, as measurement only.
