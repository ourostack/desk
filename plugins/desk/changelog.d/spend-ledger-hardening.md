Desk's direct-call spend ledger is safer under concurrency and failure: a token whose account lookup got no answer now holds its reads (`spend_held`) instead of bypassing the quota floor, a token GitHub names no account for is floored on its own answers' numbers and counted by `unattributedSends()`, `<kind>.rate` writes take a lock and only tighten within a window (racing processes and out-of-order answers cannot raise remaining), and parallel first calls with one token send a single `GET /user`. See [relays](docs/relays.md#quota).
