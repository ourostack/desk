Desk now supports authorized task and track writes from intentional named worktree branches without requiring the remote's default branch. Sessions bind the branch observed at admission and refuse later branch drift or detached HEAD before dispatch. Explicit state-branch restrictions, source and person authority, and card guards remain in force. Boot card updates and `desk_save`, including migration tidy commits, accept named branches too. See [the branch contract](mcp/README.md#the-state-branch).
