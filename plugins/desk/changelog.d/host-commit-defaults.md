Copilot's session start now shows the operator's standing grants in every session their desk homes, whatever repository it works in: the section under a `## Standing authority` heading in the desk's `AGENTS.md` (and in a Crew workspace, the person's own `desks/<alias>/AGENTS.md`) follows the startup line. A host default that waits for the user, such as the GitHub Copilot app's "commit only when the user explicitly asks" in Current checkout sessions, gives way to `AGENTS.md` guidance, so a grant there that names committing, pushing or opening pull requests is delivered on without a new message. The operator's rules and grants never go into a host's user-level instruction file such as `~/.copilot/copilot-instructions.md`. See [interaction style](skills/interaction-style/SKILL.md#standing-authority).
