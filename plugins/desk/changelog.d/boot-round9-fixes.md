### Boot prints readable text, includes the desk's rules and stops ordering ceremony

`session-boot.js` now prints plain text: a status line, the desk's path, the numbered instructions, then the open tasks, pull requests and repos, and the desk's `AGENTS.md` (up to 6 KB, with the path to read the rest when it is longer). `--json` keeps the structured result for tools and tests. Boot no longer tells the agent to read `AGENTS.md` or to confirm the Desk MCP with `desk_status`; agents skipped both in 11 of 12 acceptance runs. Instead one instruction says Desk's tools may be deferred and names the ToolSearch `select:` call that loads the exact tools, and the task-card guard's deny message carries the same hint. The sync line now says plainly what happened ("sync failed: remote unreachable; nothing was pulled or pushed; local desk is as of ..."), so a failed sync cannot be described as partial.

### A local-only repo can reach done

When a task's recorded clone has no remote configured at all, a commit that exists in that clone is valid `done` evidence, because there is nowhere to push it. A repo with a remote still needs a pushed commit or a pull request, and the refusal now says what to do: push, open a pull request, or leave the task at `validating` and tell the operator the commit sha. [`task-lifecycle`](skills/task-lifecycle/SKILL.md) and [`task-card-format`](skills/task-card-format/SKILL.md) say so, never to point `non_code` evidence at the task card itself, and that a note, commit message or reply claiming tests pass must name the command that ran them.
