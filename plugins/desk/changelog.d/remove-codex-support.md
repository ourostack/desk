Desk no longer ships Codex support. Codex was never a supported target ([RFC section 8](docs/agentic-engineering-v2-rfc.md#8-limits)), so the Codex manifests, the `.agents` marketplace, the `worker.toml` and `observer.toml` agent files, the Codex activation adapter, its smoke test and activation ledger, the Codex plugin-cache audit and the `desk:codex-onboarding` skill are gone, along with their tests and docs. Claude Code and Copilot CLI behave exactly as before. A Codex session is now reported as an unknown host, and Desk no longer reads `$CODEX_HOME/desk.activation.json`. [The hosts roadmap](../../docs/roadmap/hosts.md) says what rebuilding it would take.

Superpowers moves to 6.4.3, Plain Language to 0.2.7 and Crew to 0.2.6 because their Codex manifests are gone; their skills are unchanged, and the Superpowers payload is still upstream 6.4.2.
