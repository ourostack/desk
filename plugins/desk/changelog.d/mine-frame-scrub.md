Desk Browser `mine` redacts, wherever the main document repeats it, anything that may have been typed in a same-process iframe: field values and editable text. The frame's content is still never read. Hidden, submit, button, reset and image inputs no longer count as untyped when their value equals their markup, because the browser copies a script-set value into the markup. Only values under 8 characters are treated as page codes ("US", "0", "USD"). Longer values, such as a raw phone number a script copied from a typed field, stay redacted. See the [owned reader](mcp/web-auth.cjs).
