Normal task archival now maintains the task's structured track link and records the actual track and directory changes in the readiness journal. Already-terminal cards retain their delivery, evidence, job identity and unsigned signoff.

Git publication checks destination occupancy and companion edits before relocation, then commits only admitted bytes. A retry can reconcile an interrupted relocation whose source HEAD/index and retained bytes still match; unqualified publication remains an explicit `archive_pending` result. Late relocation failures identify the actual retained path without claiming rollback or successful publication.
