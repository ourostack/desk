Desk now reports one version everywhere an agent can see one: the Desk plugin release, such as `3.2.0-alpha.215`. Before, an agent that asked for "the Desk version" could be told the MCP runtime package's version (`1.4.0-alpha.6`), which does not change with each release. The MCP handshake, `desk_status` (`runtime.plugin.version` and the compact `plugin_version`) and `desk_doctor`'s preview answer (`mcp_version` is now `desk_version`) all say the release. The runtime package's own version stays an internal detail for the runtime pack and is no longer reported to agents.
