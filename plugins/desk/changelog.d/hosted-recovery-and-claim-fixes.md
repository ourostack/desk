Hosted Desk's recovery of a realm that couldn't be proved stopped now gives up as soon as one of its own steps can't be proved stopped either: it no longer pushes, rescues, closes the token broker or empties the realm until that new failure is recovered, so the account is never prepared again while a process of its old realm may still run. A realm now counts as saved only when its own close pushed after every service retired, never because some earlier push happened to end after the realm stopped, so a later recovery still pushes writes a still-running service made. Relinking GitHub and deleting an account now recover such a realm too, instead of failing until the replica restarts.

One repository stays one account's desk when a desk init is rolled back: the previous binding comes back suspended if another account took its repository meanwhile, and its next session start says so. A repository's claim is no longer taken over while another account's active binding still names it. The "no desk yet" page links to `/link/github` only when the gateway has GitHub linking set up.
