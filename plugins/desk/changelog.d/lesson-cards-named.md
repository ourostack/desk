`lesson_add` for a desk lesson now names the improvement card it opens: the reply carries `improvement_key` and `improvement_path`, and its message gives the card's path. The card is titled from the lesson, `Lesson for <owner>: <topic>`, instead of the fixed "System friction in the desk plugin"; the library still builds every title, and a topic that fails the credential and path scrub falls back to the fixed words. An owner `skill:<plugin>:<skill>` is accepted when the plugin is installed for any host on the machine (Claude Code's registry, Copilot's own installs, Agency's cache or Codex's plugin folder), so a lesson for MS Desk recorded from Claude Code no longer fails when MS Desk is installed for Copilot only. An unknown plugin is still refused, and the refusal now says how to file the lesson instead. `friction_add` returns the same two card fields for any system friction that opens a card. See [`lesson-owners.js`](mcp/src/tools/lesson-owners.js).
