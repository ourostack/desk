Isolated Hosted Desk keeps private desk paths out of built-in subprocess arguments and admits readiness controllers using matching real and effective Linux kernel UIDs, without requiring a passwd entry for each private realm. Invalid or unavailable kernel ownership is refused; ordinary local and legacy hosted identity behavior is unchanged.
Private triage commits resolve the linked worktree's physical common Git directory before swapping its gitfile for a directory link, and carry that context in the environment through original hooks and nested Git. This avoids Windows junction parent-path normalization without exposing the desk root in arguments or changing ordinary local Git routing. Native Windows qualification remains a separate required receipt.
