The one-time desk tidy now prints its instructions directly instead of passing them through a shell heredoc, which could block before the reader started on affected Bash installations. On Windows, migration source is read from a private temporary file instead of a native command-line argument, so long instruction blocks are not truncated by Git Bash's argument handling. A Windows timeout terminates the launcher and its shell tree before waiting for output to close; termination failures are reported explicitly. This can add up to one second after the execution deadline, plus temporary-source cleanup time, and the shell may continue until termination completes. Its instructions, claim metadata and repeat-run behavior are unchanged.
