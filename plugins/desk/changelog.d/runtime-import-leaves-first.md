The runtime server is now imported leaves first, one module per turn of the event loop, including the packages it uses such as the MCP SDK and its schema validator ([`mcp/src/runtime/chunked-import.js`](mcp/src/runtime/chunked-import.js), [`mcp/src/runtime/resolve-here.js`](mcp/src/runtime/resolve-here.js)). Before, only the server's direct local imports were split out, so one piece, or the final import of the server with the SDK, could hold the thread that answers `desk_status` for 90 to 240 ms on a loaded machine. Packages are resolved from inside the runtime's source mirror, so each one loaded early is the same file the server later imports.
