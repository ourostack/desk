The runtime server is now imported leaves first, one module per turn of the event loop, with each package the runtime uses imported as its own piece ([`mcp/src/runtime/chunked-import.js`](mcp/src/runtime/chunked-import.js), [`mcp/src/runtime/resolve-here.js`](mcp/src/runtime/resolve-here.js)). Before, only the server's direct local imports were split out, so one piece, or the final import of the server with the MCP SDK, could hold the thread that answers `desk_status` for 90 to 240 ms on a loaded machine. The longest stall is now the MCP SDK's server entry with its schema validator, 64 to 81 ms across two measurements against 130 to 137 ms before, about 40 % shorter; loading the whole server takes 120 to 170 ms longer in total. Packages are resolved from the runtime pack that the source mirror sits in, so each one loaded early is the same instance the server later imports, and a module in an import cycle is loaded only where the whole graph enters the cycle. A `#` import or self-reference that resolves into the mirror's own source is walked as source, not treated as a package.
