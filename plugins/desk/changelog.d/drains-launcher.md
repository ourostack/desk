The issue-drain poller now installs its own launcher. Every `drains.js` command refreshes `run.mjs` in Desk's drains state folder from the [launcher source](mcp/scripts/drains-launcher.mjs) shipped with the release, so a wake runner can call one stable path with no Desk checkout, and a new machine gets it from its first `drains.js status`. The launcher resolves the newest released Desk from Agency's plugin cache at run time and falls back to the last good path, logging one line, when it cannot. The command's output names the installed launcher's path and SHA-256. See [issue drains](docs/issue-drains.md).
