A newcomer joining a Crew workspace is now interviewed briefly, and the team keeps one roster of everyone it works with. `_meta/crew.json` names the roster as `people` (by default `_shared/landscape/roster.md`); `crew.js start --people <file>` records a people file the team already keeps and leaves it byte-identical, or creates a missing one from Crew's starter, which holds the team's writing rules and the questions it asks newcomers. `crew.js status` reports `people` (its path, whether it exists, whether it lists the member, and the questions, taken from the roster's `## What we ask new teammates` list or Crew's defaults). `crew.js join` takes `--about` and `--preferences`, Markdown the newcomer's agent wrote from their answers, and adds them to the new desk's `README.md` and `AGENTS.md` before its first push; it lands the agent's uncommitted roster entry in the same pull request as the desk-list row, merged three ways with what teammates changed meanwhile, and refuses any other uncommitted change. Two entries added at the same place both land; a change to the same existing lines stops at stage `people` with the desk pushed and the clone on the current default branch, so the entry can be written again. A new `crew.js roster` lands a member's roster edit on its own the same way, for a contact who came up in the work. The merge keeps the file's own line endings, so a clone with Git for Windows' `core.autocrlf=true` lands the same file as any other ([people.js](mcp/src/crew/people.js), [workspace.js](mcp/src/crew/workspace.js)).

Crew 0.2.10 adds the `crew:roster` skill, which owns the roster: where it lives, how an entry is written, the questions and how a team changes them, when to add an entry, answering "who should I ask about X?" from it, and how an edit lands. `crew:join-crew` interviews the newcomer in one chat message before the join, `crew:start-crew` names an existing people file with `--people`, and the root `AGENTS.md` Crew section names the roster. Messages now call `_meta/desks.md` the desk list, so "roster" means only the people file.
