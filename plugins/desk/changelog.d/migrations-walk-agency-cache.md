The session-start migrations skill now lists the Agency plugin cache (`~/.local/agency/plugins/cache/entries/<id>/`, indexed by `cache_index.json`) among the roots it walks for plugin `migrations/` folders. Agency installs overlay plugins there and nowhere else, so a migration shipped by an overlay such as `ms-desk` was never found in an Agency session. Desk's own migrations are unchanged: the startup hooks still run them directly.
