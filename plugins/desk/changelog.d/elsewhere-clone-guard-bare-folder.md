The clone guard now works when the hook runs from the installed plugin folder. It reads each task card's `repos:` list to decide whether a clone targets a repository the card says lives on another machine, and that list is only readable with the runtime dependencies. The hook never restored them, as boot does, so it saw every card as having no repositories and let a clone of a repository named only in `repos:` through. The guard now restores the runtime pack first, and only for a command that clones or fetches a repository, so every other command still costs one regular expression.
