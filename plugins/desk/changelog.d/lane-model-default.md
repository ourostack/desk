Lanes no longer inherit the coordinator's model. In the GitHub Copilot app, `create_session` without `kickoff.model` starts the new session on the model of the session that asked, and coordinators run on Opus, so most lanes ran on Opus too. A new Copilot `preToolUse` hook, [`hooks/copilot-lane-model.cjs`](hooks/copilot-lane-model.cjs), fills in `kickoff.model` for `create_session`, `open_issue_session` and `open_pr_session` calls that name none, through `modifiedArgs`, with `claude-sonnet-5.5`. `laneModel` in Desk's `config.json` (the state folder's `ouroboros-skills/desk/config.json`) or `DESK_LANE_MODEL` changes the default, and a model the caller names is always kept. The hook fails open, and only acts where the host runs hooks for the app's own tools, so [`work-orchestration`](skills/work-orchestration/SKILL.md) also tells coordinators to pass `kickoff.model` themselves.
