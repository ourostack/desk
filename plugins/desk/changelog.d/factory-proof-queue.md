A proof session's Factory copies now move out of the outbox at the next flush into a local folder that nothing publishes from, whether the proof was marked when the session ended or later, and no flush publishes them. The new `factory.js proof <session id>` command marks an existing local session as a proof, but only when this machine's own marker for it names a desk, and it refuses an unknown, foreign, ambiguous or ledger-only session with a reason and no content. Each attempt and each move is recorded in a local audit file that holds only a keyed hash of the session id. Nothing is deleted, and published proof records are not withdrawn by this change. The [factory documentation](docs/factory-local-capture.md#proof-sessions) describes the command.
