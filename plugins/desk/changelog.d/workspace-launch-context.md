Desk admission now passes its captured launch folder to the shared root resolver. When no known host project context exists, the resolver uses that folder as a weak project hint after validating saved activation and DESK associations, but before guessing a home-folder desk. Boot uses the same weak-hint policy. A missing saved root or DESK root, or a malformed activation file, still refuses admission even when the launch folder is a valid desk. Known host context keeps its existing stronger precedence, and non-desk hints fall through to the existing defaults. This fixes launch-folder propagation, not late-root reconciliation or session recovery.
