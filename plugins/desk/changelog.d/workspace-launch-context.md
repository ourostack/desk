Desk admission now passes its captured launch folder to the shared root resolver. When no recorded host project or host project environment hint exists, a launch folder with the Desk layout can bind instead of a home-folder fallback, matching the boot resolver. Known host context remains authoritative; non-desk folders still fall through to the saved binding and existing defaults, and invalid explicit roots still refuse admission. This fixes launch-folder propagation, not late-root reconciliation or session recovery.
