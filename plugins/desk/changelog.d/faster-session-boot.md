The session boot is about ten times faster on a busy desk: 4 to 8 s instead of 48 to 50 s with 80 open tasks, measured on a heavily loaded Mac. A boot that names no task no longer checks every task's push route or repo state; it lists the tasks and open pull requests and tells the agent to run the boot again with `--task` once the operator picks one, and that run checks the task's repos and push route. Open pull requests come from one GitHub search instead of one call per repo. Remotes are read from each clone's Git config file instead of by running `git`. The overall budget is 15 s (was 45 s). The session-start hooks print the Desk foundation within 3.5 s even on a slow machine, and neither the hooks nor the boot wait without limit on the factory status lock. The boot text lists at most 10 tasks (was 15). The removed checks and when to bring them back are in [the boot roadmap](../../docs/roadmap/boot.md).
