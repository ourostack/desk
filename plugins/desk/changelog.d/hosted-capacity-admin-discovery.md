Multi-user Hosted Desk now has capacity limits. Each account can have 3 Desk sessions open, and the gateway 12 in all. A person's 4th session is refused with a message naming the limit, unless one of their own sessions has been quiet for a minute, in which case that one gives way. At the total limit, a new session first takes the place of the person's own quiet session, then another account's session only if it has been quiet for 10 minutes, so nobody loses a session they are using to someone else. A new desk clone is refused with a clear message while the realm disk is over 80% full. At shutdown every desk pushes its unpushed commits at the same time, each as its own user; a desk whose push fails is logged by account and its realm is kept on disk. The gateway also publishes the `ouro` CLI's admin sign-in settings at `/.well-known/ouro-desk-admin` (tenant, CLI client id and the gateway's `desk.admin` scope), from `DESK_ADMIN_CLIENT_ID` and `DESK_ADMIN_SCOPE`, which provisioning sets from the identity record once the admin API is recorded.
