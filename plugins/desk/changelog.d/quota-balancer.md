[Work orchestration](skills/work-orchestration/SKILL.md) now says not to wait for a hard quota: where a host offers several authorized accounts, a resident balancer reads each account's remaining allowance from the host's own usage source, moves work to an account with allowance left before the current one runs out (at a turn boundary, never mid-turn just to rebalance), and resumes sessions a quota error stopped, so nobody switches accounts by hand. It moves only the account that pays for inference, never the one that pushes, and only within each account's permitted repositories.
