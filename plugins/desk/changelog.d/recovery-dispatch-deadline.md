Local recovery now gives the dispatched write its own 60 s budget, which starts when the call is sent and is capped so the whole run ends within 100 s, before Claude Code's default 120 s command limit ([`mcp/scripts/local-recovery.js`](mcp/scripts/local-recovery.js)). It used to share one deadline with startup, so a slow startup could leave the write too little time and turn a write the server had applied into an `unknown` result that needs a manual readback.
