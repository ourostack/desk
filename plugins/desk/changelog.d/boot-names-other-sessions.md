Boot now tells the agent which other sessions work in the same repo on this machine, in a few lines under the status line. It lists the repo's worktrees (this session's first, then those with a running session, then the most recently touched; the rest are counted), marks the shared main checkout, and says for each where a running `agency copilot` or `copilot` session has its working directory and when git there last changed. It prints the rules that follow only when there is someone else to be careful about: in a shared checkout never stash, reset, clean, switch branches or delete files you did not create, even when asked to tidy it; never touch, move or remove another session's worktree; do that work in your own worktree from `origin/main` instead. The lines come from `git worktree list`, file times and, where `ps` and `lsof` exist, the process list (Windows lists worktrees only); a step that is missing or slow is skipped, and the whole look has its own 2.5-second budget. A lone session sees nothing.

The two hooks that wait for the boot now end the wait a fixed time after their own process started (8 s for Copilot's first-prompt hook and 7 s for Claude's; 5.5 s and 4.5 s on Windows, where starting Node alone can take seconds), so a slow start shortens the wait instead of running past the hook's limit.
