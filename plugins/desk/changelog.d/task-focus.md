A new Desk tool, `task_focus`, lets a session's main agent declare the task it is working on, so the factory can credit the session's time to that task from the transcript instead of guessing from the cards it touched. It takes a `track` and `slug` (or `clear: true` for a side conversation) and answers with the card's status and its last five progress entries; it writes nothing, needs no write authority and keeps the focus in memory only. `task_create` takes `focus: true` to declare a new task in the same call. When a session is focused elsewhere, `task_update` and `task_archive` on another card, and every task tool call until the session declares a focus, add a `focus_note` hint worded for the main agent; hints never block a call.
