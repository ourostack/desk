The fleet steward now watches shipments, not just busy sessions ([`work-orchestration`](skills/work-orchestration/SKILL.md), "Waiting for children"). Each check also reads every initiative's last merge, release, live deploy and consumer adoption. An initiative with ready work and nothing shipped for about 60 minutes gets inspected, and whatever actually holds it is fixed within authority. The 60 minutes is a signal, not a quota: known-bad work is never merged, checks are never rerun blind, and real progress, reviews, security holds, running jobs and explicit stops are left alone. Work continues as each event lands, with the hourly check as the safety net. While the operator is away, the steward and at least one coordinator watch each other, and an agent that finds the steward overdue wakes it, restarts it from its checkpoint if it doesn't resume, and tells each stalled initiative's owner directly only when it can't.
