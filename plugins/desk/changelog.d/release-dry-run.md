Pull request CI now runs the Desk release as a dry run, so a pull request the release would reject fails before it merges. The new "Release dry run" job in `desk-mcp-tests.yml` folds the pending changelog fragments on the pull request merged into main, commits the result to a throwaway HEAD, runs the same checks the release runs on that commit and discards it. The release workflow and the dry run call one script, `scripts/build-and-check-release.sh`, so their steps cannot drift apart. The script also fails a release test step that matches no test file or runs no test, which had passed unnoticed. The job is one of the jobs the required "CI gate" waits for.
