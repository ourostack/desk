The general operator rules now ship inside Desk's skills, so every operator's agents follow them without a copy in the operator's own instruction file. [`interaction-style`](skills/interaction-style/SKILL.md) now says to converse in normal chat rather than through form-style question tools, to plan for a few long conversations (ask for principles, decide the instances, keep a running agenda on the task card), to stay in a conversation the human opens, and carries the coaching rule moved out of the foundation. [`using-desk`](skills/using-desk/SKILL.md) adds one clause each for the calls that are the agent's to make and the human's gates, downloading CI output and running sign-in flows without asking, merging when the repository allows it, choosing each child's model deliberately, handoffs that never tell an agent how to work, changing a constraint we authored, and designing tools for agents. The long forms live in [`work-orchestration`](skills/work-orchestration/SKILL.md) (model choice, handoffs, merging and the terminal state, the factory), [`using-superpowers-with-desk`](skills/using-superpowers-with-desk/SKILL.md) (never enter, request or recommend Plan mode), [`git-hygiene`](skills/git-hygiene/SKILL.md) (commit identity, no secrets in the desk), [`content-routing`](skills/content-routing/SKILL.md) (fold new context into existing docs, design for the agent that uses it) and [`factory-work`](skills/factory-work/SKILL.md), which [`curator`](skills/curator/SKILL.md) and [`independent-review`](skills/independent-review/SKILL.md) now point to for the Lean reading. To make room in the size-limited foundation, the detail of the coaching rule and of staying in a human-opened conversation moved to `interaction-style`, the full text of the requirements and visual-proof rules stays in `work-orchestration` and `evidence-discipline` with shorter pointers in `using-desk`, and the one-owner rule's detail moved to `content-routing`. One contract test fails if any of this wording disappears from its skill. These are instructions only: no hook, guard or setting changes.
