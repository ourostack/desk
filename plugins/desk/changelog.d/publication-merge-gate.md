Checked publication no longer merges past a repository's own validation. Before the exact-head merge, every check the base branch's GitHub rules or classic protection require must be reported and passing, and every other check reported on the head must finish passing. The published `required_checks` stay the floor. An administrator's API merge bypasses branch protection, so Desk reads the rules itself; if the rules or protection can't be read, the publication fails with that reason and never merges silently. The exact-head merge, the base-advance refusal and the five-minute timeout with its recovery route are unchanged.
