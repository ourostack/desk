`lesson_add` now puts a correction where something loads it, and its reply says whether the lesson is in effect. Before, it wrote `_meta/tips/<topic>.md`, which nothing read, so agents told people a lesson was kept when no session would ever see it. The call now needs a `scope`:

- `personal` adds a one-line rule to the `## Lessons` section of the person's AGENTS.md, which session start prints. In a shared workspace that is `desks/<alias>/AGENTS.md`, and session start now prints it after the workspace's own AGENTS.md; a shared workspace with no person for the session refuses a personal lesson instead of writing the team's file. The reply says the lesson is in effect only when it is committed and session start resolves the same person. Writes to one AGENTS.md wait for each other, and a file with Windows line endings keeps them.
- `desk` needs an `owner`: a skill of any installed plugin (overlays included), a Desk tool, the child brief or the always-on foundation. It records system friction against that owner, which opens an improvement card; the reply says the lesson is not in effect until that card's change ships, or that no card opened and why.
- `team` writes the attributed line into the root AGENTS.md of a repository the team shares (`repo`; a Crew workspace by default), through a pull request it merges itself, and cites its `source`. It works on the GitHub repository directly with an account that can push there (a fork's lesson goes to the repository it was forked from), never through the clone's checkout or remotes. The reply gives the pull request and says whether it merged and which hosts load the file; a pull request that a merge queue or auto-merge only queued is reported open, with its branch kept, until GitHub says it merged. A lesson the default branch already holds is reported in effect with no new pull request.

Session start prints the desk's and the person's AGENTS.md from one 16 KB budget and keeps its whole output under 28,000 characters, the most Claude Code shows in full. To stay under that it shortens the list of tasks, pull requests and repos first and cuts an AGENTS.md only when the files alone do not fit, saying which under the status line. A lesson that would fall outside the part of AGENTS.md session start prints is refused, and the same lesson recorded twice in a day changes nothing and stays in effect. Existing tips files stay searchable; [lesson-capture](skills/lesson-capture/SKILL.md) now records each lesson this way.
