Desk now ships to Agency through a `release` branch. The release workflow moves it to each stable release in the same push that puts the release on `main`, after `main`'s full CI passed, so an install of `github:ourostack/desk:plugins/desk@release` no longer runs merged changes that are not released yet. Install and dependency coordinates for Desk itself change from `@main` to `@release` ([README](README.md#under-copilot-cli)); Superpowers, Plain Language and Crew stay on `main`. `scripts/check-dependency-channels.cjs` requires `@release` for a dependency on Desk, and the stale-Desk refresh finds a `@release` install as well as an older `@main` one.
