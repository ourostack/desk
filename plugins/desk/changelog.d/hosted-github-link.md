Hosted Desk gains verified GitHub linking at `/link/github`, behind the browser session. A person links a repository as their desk only when the Ouro Desk GitHub App is installed on it and GitHub says they can push to it: the repository must appear in their own installations, and the App's installation token must confirm both the installation and write, maintain or admin permission. One repository is one account's desk, whatever the case of its name. The binding keeps the GitHub user id and login, and the commit author becomes their GitHub noreply address. The user token is used only during GitHub's callback and is never stored. A repository that isn't a desk yet is offered `desk init`; declining links nothing, and a failed init puts back the previous binding. At each Desk session start, `sessionRefusal` checks the binding again. When GitHub says the permission or the installation is gone, the binding is suspended and the session is refused with a link to relink, until a later check passes or the person links again. A rate limit, a GitHub outage or a fault in our App's own credentials refuses that session with "try again" and never suspends anything.
