The derivers and the publishing transform now fill published facts `/4`, and every file the flush sends is `/4` ([`publish.js`](mcp/src/factory/publish.js)). Each job whose card was seen done or cancelled carries its UTC finish day, from the session's own last move of the card into that status, else from the card's `updated` time as an upper bound; a desk whose remote is public still publishes no finish day. Each pull request says whether the session's own call created it: Claude Code marks it from the creating `gitOperation`, never from a `pr-link` line alone, because on real transcripts that line is also written for pull requests the session only looked at; Copilot marks none, and a public desk marks none. Each human wait carries the mechanical facts of why the agent stopped: how its turn ended (the reply's stop reason, a rate limit or other API error, the operator's interrupt), whether its last reply ended in a question mark and, on Claude Code, whether its own background agents were still running ([`derive-claude.js`](mcp/src/factory/derive-claude.js), [`derive-copilot.js`](mcp/src/factory/derive-copilot.js)). A Claude Code `AskUserQuestion` or `ExitPlanMode` call the operator answered is now also a human wait spanning the call, so the reports can count that time as waiting rather than working; once the reports do, working time and flow efficiency fall for tasks that used those tools. No text and no tool name leaves the deriver. The re-derive version is now 7, so every ended session still on disk is derived once more and republished with the new keys, and a session whose transcript is gone still gets its finish day from the local facts it already has. The RFC's privacy statement and [local capture](docs/factory-local-capture.md) describe the change: no identity and no content are published, one finish day per task is, and every other time is on the task's own clock.
