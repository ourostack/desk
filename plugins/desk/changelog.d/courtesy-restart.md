[Work orchestration](skills/work-orchestration/SKILL.md): restarting an agent host is now a courtesy. Agents still never wait for idle sessions, but they never pull a host out from under a person who is using it: they show a small notice that takes no focus ("needs a restart to <reason>.") with Restart now and Not now buttons; closing it means Not now, never go. Once it is up, they restart only on Restart now, or when the screen locks, the display sleeps, the screen saver starts, or 20 minutes pass with no input and no call. Restarts of the host and of the whole machine share one queue on the machine, which is the only way agents restart either. The watcher that resumes sessions now counts work the restart killed (a shell or subagent a session was waiting on), resumes within seconds of the host answering, confirms each message arrived and was acted on, sends again until it was, and is never replaced by resuming sessions by hand. It also resumes sessions whose runtime the running host shut down, such as when an account switch evicts a project's sessions.
