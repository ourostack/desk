[Work orchestration](skills/work-orchestration/SKILL.md): restarting an agent host is now a courtesy. Agents still never wait for idle sessions, but they never pull a host out from under a person who is using it: they show a small notice that takes no focus ("needs a restart to <reason>. Close this when you're ready.") and restart when it is closed or the machine is idle. Restart requests share one queue on the machine, which is the only way agents restart the host. The watcher that resumes sessions now counts work the restart killed (a shell or subagent a session was waiting on), resumes within seconds of the host answering, confirms each message arrived and was acted on, sends again until it was, and is never replaced by resuming sessions by hand.
