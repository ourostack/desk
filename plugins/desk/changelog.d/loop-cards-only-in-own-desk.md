Keep the improvement loop's machine-wide cards out of other desks, and its commits out of a person's way. The loop's route step (cards for andon issues, failing store builds, Desk problems and this machine's status) and the measure step's loop alarms now write only into the person's own desk: the one their saved binding, `$DESK` or home folder names, without the session's project folder (`mcp/src/factory/route-desk.js`). Before, a session opened in a project or throwaway desk received every such card, one commit each. In any other desk the route step reports `not_own_desk` and is not recorded, so the own desk's next run still routes. Desk's own writes now wait up to 3 s for a Git lock another process holds, instead of failing; the loop worker runs with `DESK_GIT_YIELD=1`, so its card commits never wait and give way (`deferred`) when the index lock is held, and a later write commits the card.
