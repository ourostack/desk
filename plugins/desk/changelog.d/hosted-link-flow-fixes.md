Hosted Desk's GitHub linking can now be found and finished by an invited person. On a multi-user gateway the invite page sends them to sign in and link their GitHub desk before they connect Claude, and the "no desk yet" page and the account page both link to `/link/github`. "Make it a desk" now works on an empty repository: the clone starts a `main` branch, desk init commits to it, and the first push creates it on GitHub.

One repository is now one account's desk atomically. Linking claims the repository in a new `repoclaims` table before writing the binding, so two people linking one repository at once can't both succeed. Linking another repository, a rolled-back desk init and deleting an account free the claim. A suspended binding whose repository has since become another account's desk stays suspended when access returns, and its session start says so.

A session-start recheck no longer overwrites a link made while it ran: its writes are conditional on the binding it read, and a changed binding is rechecked instead. A binding the operator seeded, with no GitHub user, is now rechecked too: it is suspended when the Ouro Desk App's installation no longer serves its repository. Signing out now ends every browser session of the account, including a copied cookie.

Fixed: in an isolated hosted realm, `task_update` refused to finish a task with a PR, or to record a step's PR, when the card named a local clone outside the desk. Done evidence now treats such a clone as one Git can't answer for and matches the PR by the recorded repo name.
