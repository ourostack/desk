### The decision-only-the-human-can-make rule and the headless fallback are sharper

`skills/interaction-style` now has one bullet for every decision only the human can make (an edit or purchase, a send in their name, the scope of a permanent deletion): the last message ends with one question per decision, says what each choice does, and recommends one, even when the host cannot collect an answer. The reason for avoiding a question form and the native-consent line are to be put in the last message too.

`skills/using-desk` tells a worker whose host forbids asking for go to end the alignment note with "Implementation waits for your go." instead of saying the host forbids asking, relays "the time you will report the measured numbers" for an unmeasured date, and disables host memory in the host's settings.
