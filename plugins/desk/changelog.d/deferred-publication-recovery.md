`local-recovery.js` can now write a card in an existing checkout that no session binds, such as a publisher's own clone, and leave publishing to the caller. With `--publication deferred`, the server it owns commits each write through the ordinary admission, authority, card validation and card guard, but never schedules a push, and the report gives `effects.push: "deferred"`. Previously every card commit started the background push worker, which a configured upstream turns into publication, so a caller with its own checked publication route had no supported way to stage the change. Only the launch argument defers publication; an inherited `DESK_PUBLICATION` variable is cleared, so an ordinary session's pushes can't be stopped by accident.
