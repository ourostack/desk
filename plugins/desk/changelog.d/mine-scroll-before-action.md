Desk Browser `mine` scrolls an element into view before it clicks, fills or otherwise acts on it. Playwright waits for a control to be enabled before scrolling to it, but GitHub's OAuth and device-flow "Authorize" button is enabled only once it has been seen. Below the fold, that click waited until `AUTH_TIMEOUT`, which then closed the context. It now completes in about a second. See the [owned reader](mcp/web-auth.cjs).
