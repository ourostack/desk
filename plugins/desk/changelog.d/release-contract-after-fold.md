The Desk release works again. Every release since the factory loop change failed, because a content contract read that change's changelog fragment, and the release folds the fragment into the changelog and deletes it before it runs the checks. The contract now reads the fragment while it exists and the same paragraphs in the changelog once the release has folded them. The release also ran its Node test step against folders that no longer exist since the Desk tests moved to `tests/desk/`, so that step found no tests and passed silently; it now points at the real folders and runs the release, activation, artifact, docs and script tests on the release commit.
