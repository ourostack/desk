**A file write or commit that only touches a task's card no longer creates or joins its job.** Binding treated any successful write, or any desk commit, landing inside a task's folder as work on that task, including one that changed nothing but `task.md` itself — the card housekeeping touches on every tidy pass, track rename, scope-line edit or their reverts. That let bulk desk reorganizations manufacture spurious jobs, one per task folder they merely renamed or relabeled, with no working session behind any of them. A write or a commit whose only change inside a task's folder is the bare card now binds nothing there; a `task_update`, `task_create` or `task_archive` call still binds exactly as before, since it never went through this path, and a commit or write that changes anything else in the folder alongside the card still binds as before too.
