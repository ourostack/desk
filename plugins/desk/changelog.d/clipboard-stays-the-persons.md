[Work orchestration](skills/work-orchestration/SKILL.md) now says agents never use the system clipboard as staging or transport for their own work on a machine a person uses. It is the person's, it spans their devices (a read can pull another Mac's clipboard and leave a stuck "Pasting from…" box on their screen), and endpoint DLP agents read every change. Text moves between steps in files or a private named pasteboard instead; a clipboard read or write the person explicitly asks for stays theirs to grant.
