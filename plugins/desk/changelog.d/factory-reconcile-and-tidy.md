A controller that works several jobs in one session no longer has its whole time copied into each of them. The binder now records, for each of the controller's jobs, the spans of the session its own evidence gives that job (Desk tool calls, file writes, desk commit windows and its spawns), the factory pipeline counts only those spans of the controller's time toward the job, and a pull request the controller opened goes to the job whose span holds its creation time. Only a span that two jobs genuinely share is still counted in both and marked `worker_shared`. Facts written before this change keep their old numbers, and a public desk publishes neither the spans nor the pull request times.
