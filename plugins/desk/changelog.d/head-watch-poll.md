`desk_status` keeps its 200 ms answer when the desk's destination changes. The session watched the desk's `.git` folder for `HEAD` changes, and dropping that watch for the old desk closes it synchronously on the event loop: on macOS that took from 0.5 s to over 2 s, and every `desk_status` call waited behind it. The session now polls `.git/HEAD` every 500 ms instead ([`mcp/src/runtime/desk-session.js`](mcp/src/runtime/desk-session.js)). Stopping a poll only stops a timer, and a poll by path also follows the new file Git renames over `HEAD`, so a `HEAD` change is still noticed without a tool call, within about 0.6 s.
