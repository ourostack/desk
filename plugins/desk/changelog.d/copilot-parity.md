Copilot sessions get more of what Claude Code sessions get. Plain Language now reaches every Copilot subagent through Copilot's `subagentStart` hook, as it does on Claude Code through `SubagentStart`. Desk's Copilot session start turns off the `ask_user` question form once when the operator has not chosen (`askUser: false`), as it already did for the AI co-author trailer, so Copilot's worker asks in plain chat like Claude's. Copilot's `sessionStart` hook may now take 10 seconds, the same limit Claude Code's has, instead of 5, so a slow machine no longer cuts it off before the foundation arrives. SETUP.md has a full Copilot CLI section, and the docs name the agent `desk:worker` everywhere and say to start Copilot with `agency copilot --agent desk:worker`, because Copilot has no setting that makes a plugin's agent the default.
