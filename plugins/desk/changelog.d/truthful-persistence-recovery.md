Persistence failures no longer turn an unreadable Git state into an unchanged or non-Git save. Failed commits retain uncertain effects and local HEAD observations; partial file writes name the completed and uncertain paths. Mutation exceptions require readback before another dispatch, while read-only calls retain retry advice. Successful responses stay unchanged ([implementation](../mcp/src/tools/desk-save.js), [qualification](../../../tests/desk/mcp/__tests__/tools/persistence_outcomes.test.js)).

Archive retry can publish an exact staged relocation without consuming unrelated staged work. Changed payloads, partial staging and outside track edits remain pending. A commit timeout still requires reconciliation and is not diagnosed or removed by this change ([implementation](../mcp/src/tools/archive-state.js), [qualification](../../../tests/desk/mcp/__tests__/tools/archive_staged_retry.test.js)).
