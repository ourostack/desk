`desk:session-start` now boots with one command. `mcp/scripts/session-boot.js [--task <name>]` (backed by `bootOnce` in `mcp/src/runtime/boot.js`) checks Desk's own migrations, resolves `$DESK`, probes the host, checks `gh`, `jq` and `gh auth status`, syncs the workspace, reads the cheap filesystem task index, validates every task card's frontmatter, resolves a push-capable GitHub account for every task repo, fetches each open task's local clones, looks up open pull requests, and resolves a named task, all in one line of JSON that always exits 0. Every slow step has a wall-clock budget and comes back under `pending` instead of hanging, and the sync counts against the same budget.

The result has one `status` word (`ready`, `degraded` or `setup_required`) with a `degraded` list, never two contradictory state words, and an `instructions` array of plain sentences naming the exact file, command, task or repo to act on: finish a pending migration, hard-stop on a missing prerequisite, read the desk's `AGENTS.md`, hand a named task to `session-resumption`, update a task card's Host line only when the host changed, and the factory consent steps with the expectation that a noninteractive session neither asks nor records. `covers_hosts` states that the script serves Claude, Copilot and Codex. The boot script has no `CLAUDE_PROJECT_DIR`, so root resolution falls back to its working directory when that is itself a desk, as `desk/tidy.js` already does.

Two fixes ride along. A host authenticated only through `GH_TOKEN` or `GITHUB_TOKEN` is no longer reported as `auth_stale`, and counts as one push account. Card validation accepts unquoted YAML timestamps (which parse as dates) and, when `gray-matter` is not installed, skips the `repos` checks the dependency-free reader cannot perform instead of flagging every card.

`session-start/SKILL.md` shrinks from about 40 KB to about 7 KB: run the command, act on `instructions`, and keep the judgment rules (first-reply content, deciding instead of asking, the Desk MCP availability checkpoint, resume hand-off). The cases only some sessions need (MCP repair, crew workspaces, the friction backlog, Factory boot lines) move to `session-start/details.md`, which the skill links at the moment each applies. The `Desk boot: workspace-tidy budget exceeded; deferred` line is explained as needing no action.
