A person's own `AGENTS.md` in a shared workspace now always gets at least 8 KB of what session start prints, however large the team's root `AGENTS.md` is, and `lesson_add` judges where a personal lesson lands by the same floor. Before, a root file of 16 KB or more left the person's file nothing, so their preferences and new lessons never reached a session ([#659](https://github.com/ourostack/desk/issues/659)).

The `using-desk` foundation now says never to write instructions, lessons, preferences or context into a harness home folder such as `~/.copilot` or `~/.claude`: it belongs to one machine, unsynced and unshared, so a rule that does not load is fixed where it loads from.
