Every fresh Desk install now has a working browser. Desk declares a `playwright` MCP server on Claude and on Copilot, started by the new [`mcp/browser.cjs`](mcp/browser.cjs). It runs `@playwright/mcp@latest` from its npm channel with no pinned version, under the same compatible Node that Desk's bootstrap picks. The browser runs headless, so agents never take the operator's focus, and isolated, so concurrent sessions never share a profile. It uses Chrome, or Edge when Chrome is not installed. `SETUP.md` now lists Chrome or Edge as a prerequisite and checks that the browser opens a page. Authenticated browser contexts still go through the claims-based broker and `desk:cdp-headed-browser`.
