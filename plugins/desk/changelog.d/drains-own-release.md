The drain launcher fetches Desk's `release` branch itself, into its own shallow clone next to `run.mjs`, each time it starts (one `git ls-remote`, a fetch only when the branch moved), so a Desk release reaches the drains within one poll cycle instead of waiting for Agency's plugin cache; the Agency cache and the last good path remain as fallbacks. `drains.js status` and `poll` now name the Desk in use (version and release commit). A poll now also reads an issue's timeline when its `updated_at` moved and nothing else was news: a cross-reference that is not the drain's own work (its marked comment, a marked body or a `drain-` pull request) wakes the drain and names its source; the drain's own never does. See [issue drains](docs/issue-drains.md).
