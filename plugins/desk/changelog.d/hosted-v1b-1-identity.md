Hosted Desk's signing key can now roll over without signing anyone out: after a rotation the gateway signs with the new key and still accepts tokens sealed with the previous one until `DESK_SIGNING_KEY_PREVIOUS_UNTIL`, 30 days later. Client ids are sealed with their own `DESK_CLIENT_KEY`, which falls back to `DESK_SIGNING_KEY` until a previous key is set, so registered clients keep working through a rotation. The gateway refuses any key holding whitespace and logs each key's fingerprint at start, never the key. See [`hosted/README.md`](../../hosted/README.md).

Hosted Desk has an accounts store for Ouro accounts, not yet used when signing in: Azure Table Storage tables for accounts, sign-in identities, invites and each account's desk binding, reached through the gateway's managed identity, with an in-memory twin for tests and local runs. An invite is a single-use link whose token the store never keeps, only its SHA-256; two people redeeming one invite at once get exactly one account mapping, an identity that already has an account can't redeem another, and an expired or used invite is refused. A 60-second account cache sits in front of the store and fails closed: when the store can't answer and the cached row is older than a minute, the account check refuses. The gateway tests now also run against Azurite in CI.
