`desk_status` now names the step a running admission attempt is in. The `admission` object gains two fields: `phase`, the current step, and `phase_since`, when that step began (both `null` when no attempt is running). A start that sits in "admitting" used to say only that; it now says which step it is in: `resolving_inputs`, `loading_runtime`, `inspecting_state_branch`, `admitting_authority`, `verifying_authority`, `connecting_controller` and `checking_semantic_readiness`, with these steps of the runtime load shown while `loading_runtime` runs: `inspecting_runtime_pack`, `restoring_runtime_dependencies`, `mirroring_source`, `waiting_for_publication_lock:<folder name>`, `building:<folder name>` and `importing_runtime`. When authority is already admitted, a later attempt shows `admitting_authority` and then `checking_semantic_readiness`. The runtime load reports its steps from the admission worker thread as it goes, so a worker blocked on a lock still shows where it is. No existing field changes.
