Hosted Desk provisioning now owns the per-account desk switch: `DESK_MULTI_USER=1 hosted/infra/provision.sh` turns it on, `DESK_MULTI_USER=0` turns it off, and a rerun keeps the app's value otherwise. It refuses `1` before writing anything unless the identity record is complete, because the gateway won't start in multi-user mode without Ouro accounts, and `REMOVE_OURO_SETTINGS=1` takes the switch off too. Every rerun now also sets the shutdown grace period to 120 seconds, so apps created at 90 seconds pick up the longer shutdown without being created again.
