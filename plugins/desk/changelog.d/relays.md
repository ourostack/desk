The drains runner now runs relays, two small GitHub automations for a repository whose own settings cannot do the job. A `dispatch` relay fires a workflow or a `repository_dispatch` event once when a watched workflow has a new successful run. A `merge-when-green` relay merges a labelled pull request only when every check it names is green on the head and, if asked, the base branch's latest completed run of a workflow is green; it never bypasses the branch rules and keeps one status comment it edits. Both poll with conditional requests and back off on a low quota. `drains.js status` lists each relay with its last fire or merge and what it waits on, and `drains.js why --relay <name>` and `drains.js why owner/name#number` show what a relay decided. See [Relays](docs/relays.md).
