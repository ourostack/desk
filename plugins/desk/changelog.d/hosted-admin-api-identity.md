Hosted Desk's identity provisioning now keeps the admin API in place in each Ouro tenant: the gateway app exposes the delegated scope `desk.admin` and the user app role `ouro.admin`, the `ouro-cli` public client is preauthorized for that scope on its loopback redirect and included in the user flow, and exactly the users listed in `adminApi.admins` hold the role. `provision-identity.mjs --admin-api` reconciles just these pieces as the tenant's admin app, without `az` signed in to the tenant.
