A factory store's build now checks kaizen cards and pulls the andon cord ([factory-local-capture.md](docs/factory-local-capture.md)). `factory.js kaizen-check` reads each open issue labeled `kaizen`, parses its `yaml` card, and once the card names the version that first carries its countermeasure, compares the card's measure between finished jobs before and after that version: both medians, the change, and a 95% bootstrap interval from 10,000 resamples seeded with the card's number. The card gets `confirmed` or `not-confirmed` only when the interval lies wholly on one side of zero, keeps exactly one comment from the build, and is never closed by it. `factory.js andon` compares each plugin's latest version with the version before it on every quality measure and opens one `andon` issue per clear regression, updates or reopens it, closes it when a later version recovers or the data no longer shows it, and leaves alone any alarm a reviewer labeled `not-confirmed`. Below two jobs on either side there is no interval, so neither step claims anything from a single job. The [store playbook](docs/factory-store-playbook.md) carries the new build steps and a kaizen issue form.
