Desk Browser `mine` reads pages that contain iframes, such as amazon.com product pages, instead of refusing them with `AUTH_FRAME_COVERAGE_REFUSED`. The [owned reader](mcp/web-auth.cjs) reads the main document; each iframe, frame or embedded object shows as an empty `frame` node, its child document, fallback content and controls are never read, and the result's `framesOmitted` counts them. Only the main frame's own navigation invalidates a read, so busy ad frames no longer do.

Large real pages read too: the main document may have up to 100,000 nodes (was 20,000), and the native packet up to 2,000,000 values (was 200,000). Hidden (`display: none`) text takes the editing mode of its nearest rendered ancestor, or `contenteditable` on the way, instead of counting as possibly typed, and hidden, submit, button, reset and image input values that equal their markup are page content. Before, those values redacted every matching letter or digit in the page ("USB 5.0" read "[redacted]B 5.[redacted]"). Typed values, editable content and text, number and other typeable fields stay protected as before.
