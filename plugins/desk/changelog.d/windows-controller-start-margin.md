On Windows, the readiness controller now gets 30 seconds to start instead of 15, so a loaded machine no longer fails a session with "readiness controller child startup timed out": a controller was measured starting in 14.896 seconds against the 15 second window (issue 255), and the window now keeps twice that margin. A controller that dies still fails the start at once with its own reason, because the window only bounds a controller that is alive and silent. macOS and Linux keep 10 seconds.
