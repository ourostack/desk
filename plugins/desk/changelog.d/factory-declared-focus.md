Desk now lets a session say which task it is working on, so the factory credits each job with the work that was really done on it. The new `task_focus` tool takes a `track` and `slug` (or `clear: true` for a side conversation that belongs to no task), answers with the card's status and its last five progress entries, and writes nothing. `task_create` takes `focus: true` to create a task and declare it in one call. The `using-desk` foundation and the session-start, start-task, session-resumption, task-lifecycle and Superpowers skills now tell the main agent to declare the task once, when it picks or switches to one, and tell every subagent never to call it: the brief a Superpowers mapping produces carries `Never call task_focus; your work is credited through the Desk-Task line.` right after its `Desk-Task:` line. While a session has no focus, every task tool result carries a short hint for the main agent, and `task_update` or `task_archive` on another card carries one too. Hints never block a call. While the server is still starting, `task_focus` waits up to 2 seconds for it and then answers or refuses.

The factory now credits time by declaration first and by inference only where nothing is declared. Touching a card no longer makes a session part of that task: creating, updating or committing another card, and another session's commit that happens to land during a session's own `git commit`, bind nothing. Work in a code repository counts only for the one card that lists that repository. A short inferred stretch joins its longer neighbour, and a stretch you declared is never merged or dropped. Background subagents stay with the job they were spawned for, so reviewers and implementers no longer fall out of their task. A session now counts as shared between jobs only when their segments really overlap, and each job's time comes from its active intervals, not from the wall-clock span of a segment. Each session's local receipt records how it was bound (`bound_by`), its own activity, where inference disagreed with a declaration (`focus_disagrees`), how much time the segment limit dropped (`segments_capped_ms`) and how many directories had no repository evidence available (`repo_unresolved`); an absent value means it was not recorded, never zero. A task that was moved or renamed keeps its job.

Sessions whose capture marker was pruned after 30 days are now rebuilt from their transcripts in desks that declare their store, when it is safe to; the rest stay frozen, and each sweep records how many it rebuilt, how many it left frozen and why, and how many are pending.

`factory.js reconcile` now lists only tasks with real work in the window, places each task by the segments of its sessions, and counts cards touched only by housekeeping as `housekeeping_cards` instead of listing them (`mechanical_only` is gone). It reports `not_bound` for real commits that no session's own activity owns (this replaces the misleading `no_marker`), `status_unobserved` when a card's status changed while its session was focused elsewhere, and `focus_disagrees` when a declared stretch holds none of its job's own events. It counts `mentioned` commits made on a task by a session bound to another task, shows each task's story (its sessions in order, with active time and how each was bound) and counts the bindings by `focus` and `inferred`, and lists the sessions with the segment time that was dropped and the repository evidence that was not available, saying "not recorded" instead of 0 when a measure was never taken.

The one-time tidy and its revert now end their commit message with the trailer `Desk-Tidy: true`, so the factory and `reconcile` treat them as housekeeping, not as work on the tasks they moved. The factory documentation also gains a "Working on the factory" section: every factory design, plan and review starts from Lean and the sealed, self-sustaining "terrarium" idea, and a loop that stops at noticing or filing is not a loop.
